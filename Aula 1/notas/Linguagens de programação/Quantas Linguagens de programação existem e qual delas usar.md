Existem diversas linguagens e seus usos estarão atrelados ao tipo de problema que se deseja resolver. Cada linguagem tem seu propósito e algumas são melhores para certos tipos de programas que outras:
Exemplo:
-	Typescript e Javascript: 
	-	São feitas e projetadas para web, mais especificamente em frontend, apesar de tambem serem interessantes para backend;
-	Java: 
	-	Muito utilizada ainda hoje em dia em backend, jogos e apps móveis. Já teve sua versão compatível com web, que foi descontinuada há alguns anos
-	Python:
	-	Linguagem mais utilizada em análise de dados, mas que tambem serve para outras finalidades como jogos, apps desktop e mobile, APIs (principalmente rest com django) e aplicações de prompt de comando;
-	C#:
	-	muito utilizada em aplicações web com o framework ASP.NET core, mas tambem muito utilizadas em desenvolvimento de jogos com Unity e Godot + C#;
-	C++:
	-	Muito utilizada em desenvolvimento de jogos e dispositivos embarcados (que não são computadores), mas não funcionando muito bem para backend;
-	C:
	-	A "mãe" das linguagens de programação modernas. A maioria das linguagens seguem o padrão de sintaxe do C, que é uma linguagem muito utilizada em dispositivos embarcados e, junto com pascal, é considerada uma das primeiras linguagens de programação de alto nível. Foi o divisor de águas no mundo da tecnologia.
